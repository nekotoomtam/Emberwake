LeftRig.tscn instances Rig.tscn with a horizontal display reflection. Both face
directions share bone-local coordinates, contour data, poses, and layer order.
Near/far identify depth relative to the viewer. The mirrored view preserves
the near/far order and reflects the bone guides with the character.

Open project.godot and press F6 on LeftRig.tscn or F5 for the default left view.
Left/Right arrow: select pose. Space: play. B: show bones.
