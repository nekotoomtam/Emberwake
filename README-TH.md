Emberwake v115 - ทางขึ้นกลางเรือแบบเดียวกัน

เอาตลาดชุดหน้าเรือและลานรั้วเดิมออก พร้อมจุดชนที่เคยกีดขวาง
เรือทั้งสองฉากใช้โมเดลต้นแบบเดียวกัน จุดขึ้นอยู่กลางลำตรงกัน
สะพานใช้ขนาด วัสดุ ไม้กระดานและราวเชือกเดียวกัน ย้ายท่าและช่องรั้วให้ตรงจุดขึ้นใหม่
เอากล่องบนดาดฟ้าและจุดชนออกทั้งหมด ตัวละครกับน้ำทะเลที่ผ่านแล้วคงเดิม

ภาพจากเกมจริง: docs/previews-v115 รอบนี้ถ่ายแบบไม่แสดงหน้าต่างเกมและปิดกระบวนการถ่ายเมื่อเสร็จ
ทดสอบเดินจริงจากคาเฟ่ ขึ้นเรือ และลงกลับลาน ครบ17จุด พร้อมกระเป๋าที่ถือ
