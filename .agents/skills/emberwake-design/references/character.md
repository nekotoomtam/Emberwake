# Character design

## CHAR-001 — Translate role into visible choices

Start from the selected reference, role, personality, and any approved identity traits. Pick a few visual signals a player can read, such as silhouette, posture, equipment, or dominant value groups. Explain which traits vary across concepts and which identify the same character.

## CHAR-002 — Review in the intended view

Compare concepts beside the selected reference at matched scale. Check at actual game size in the current camera, including the facing directions and combat poses that matter to the target build. For variations, compare the resulting silhouette and key identifiers across views. Label unseen forms or new details as proposed where relevant.

## CHAR-003 — Route rig work to the specialist workflow

For four-view 12-part breakdown, pivot placement, and seam or motion QC, use the installed `emberwake-cutout` skill when available. Use `stylized-anatomy-rig-review` for stylized proportions and joint construction. Keep concept approval, fidelity to the selected drawing, and motion approval separate.
