# Character design

## CHAR-001 — Translate role into visible choices

Start from the selected reference, role, personality, and any approved identity traits. Pick a few visual signals a player can read, such as silhouette, posture, equipment, or dominant value groups. Explain which traits vary across concepts and which identify the same character.

## CHAR-002 — Review in the intended view

Compare concepts beside the selected reference at matched scale. Check at actual game size in the current camera, including the facing directions and combat poses that matter to the target build. For variations, compare the resulting silhouette and key identifiers across views. Label unseen forms or new details as proposed where relevant.

## CHAR-003 — Route rig work to the specialist workflow

For four-view 12-part breakdown, pivot placement, and seam or motion QC, use the installed `emberwake-cutout` skill when available. Use `stylized-anatomy-rig-review` for stylized proportions and joint construction. Keep concept approval, fidelity to the selected drawing, and motion approval separate.

## CHAR-004 — Use the selected art direction for Emberwake images

When the user asks to create or edit an image for Emberwake, use the selected hand-drawn 2D gothic storybook direction by default. Follow any art direction given for the specific image. Open the [selected blonde heroine illustration](../../../../docs/art-reference/blonde-heroine/blonde-heroine-rough-ink.png) and its [original prompt and input references](../../../../docs/art-reference/blonde-heroine/prompt.md) before writing the generation prompt.

- For characters, use rounded chibi proportions, simple oval eyes, and a readable silhouette. Keep asymmetry in the pose, hair, or drape. Use irregular ink contours, occasional doubled or broken strokes, sparse hatching, and muted matte watercolor washes. Preserve the selected costume details when making the drawing feel rougher by loosening the lines and shadows.
- For other subjects, carry over the ink, watercolor, and surface treatment. Use a subject-specific reference when available. Use the heroine as a style reference for new subjects, and preserve the requested subject's own shape, colors, and details.
- Use the image generation tool for raster concepts and edits. For a new character, adapt the saved prompt to the requested role, outfit, pose, and equipment. For a faithful redraw, attach the approved image of that character as the identity reference. Review the result against the selected reference at the intended viewing size. Treat a mockup as a concept and integrate it into the game when requested.
